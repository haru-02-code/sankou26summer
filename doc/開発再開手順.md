# 映画・アニメ視聴ログアプリ - 開発再開時の手順

## 1. Anaconda Promptを開く
スタートメニューから「Anaconda Prompt」を検索して起動

## 2. 仮想環境を有効化する
```
conda activate sankou_26_summer
```
→ プロンプトの先頭が `(sankou_26_summer)` になっていればOK

## 3. プロジェクトフォルダに移動する
```
cd C:\HAL-src\movie_log_app
```
（パスは実際の保存場所に合わせる）

## 4. MySQLサーバーが起動しているか確認する
```
mysql -u root -p
```
ログインできればMySQLは起動している。確認できたら一度ログアウトしておく。
```sql
exit
```

## 5. エディタ（VSCode等）を開く
`movie_log_app` フォルダを開く

## 6. アプリを起動する
```
python app.py
```

## 7. ブラウザで確認する
```
http://127.0.0.1:5000
```

## よく使うMySQLコマンド

### テーブルのカラムを確認する
```sql
DESCRIBE movies;
```
または
```sql
SHOW COLUMNS FROM movies;
```

### テーブルの作成SQLを確認する
```sql
SHOW CREATE TABLE movies;
```

### データを確認する
```sql
USE sankou26s;
SELECT * FROM movies;
```

### SQLファイルから一括実行する（mysqlにログインする前の状態で）
```
mysql -u root -p < database.sql
```

## Git（GitHub）関連コマンド

### 作業のたびに行う一連の流れ
```
git status
git add .
git commit -m "変更内容の説明"
git push
```

### 各コマンドの役割
| コマンド | 役割 |
|---|---|
| `git status` | 変更されたファイルを確認する |
| `git add .` | 変更をステージに追加する（`.`は全ファイル対象） |
| `git commit -m "説明"` | 変更内容を記録する |
| `git push` | GitHubに送信する（初回は`-u origin main`が必要） |

### コミットメッセージの例
```
git commit -m "登録・一覧表示機能を実装"
git commit -m "UPDATE/DELETE機能を実装"
git commit -m "正規表現バリデーションを追加"
```
